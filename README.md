# سلام 👋 من توسعه‌دهنده وب، ربات و اتوماسیون هستم

سایت‌های کدنویسی‌شده، فروشگاه اینترنتی، ربات‌های تلگرام و بله و اتوماسیون کارهای تکراری می‌سازم؛ **سریع، تمیز و با پشتیبانی بعد از تحویل.**

---

## 🌟 نمونه‌کارها

### 🏢 وب‌سایت شرکتی هیروسان — [www.herosunco.ir](https://www.herosunco.ir)
وب‌سایت رسمی گروه تولیدی و بازرگانی هیروسان، توزیع‌کننده قطعات یدکی خودرو در کرمان و جنوب شرق ایران.

- طراحی و کدنویسی اختصاصی (HTML / CSS / JavaScript) بدون قالب آماده
- صفحات: خانه، درباره ما، برندها، محصولات، رویدادها، فرصت‌های شغلی و وبلاگ
- ریسپانسیو برای موبایل و تبلت، با تمرکز بر سرعت و اعتمادسازی برای مشتری
- معرفی زنجیره تأمین، برندهای همکار و سبد محصولات

🔗 **[مشاهده سایت](https://www.herosunco.ir)**

### 🤖 رادار پروژه‌های فریلنسری (ربات تلگرام + بله)
رباتی که سایت‌های فریلنسری ایرانی را ۲۴ ساعته بررسی می‌کند، پروژه‌های مرتبط را پیدا می‌کند و با کمک هوش مصنوعی قیمت، زمان تحویل و متن پیشنهاد آماده می‌کند.

- پایتون، asyncio، API تلگرام و بله، SQLite
- هوش مصنوعی (DeepSeek / سازگار با OpenAI) برای نوشتن پیشنهاد و دستیار مذاکره با کارفرما
- دکمه‌های تایید، ویرایش و رد؛ ثبت درآمد ماهانه و گزارش پیشرفت تا هدف
- تست خودکار و استقرار ۲۴ ساعته روی سرور لینوکس (systemd)

> کد این پروژه خصوصی است؛ در صورت نیاز، دموی زنده نشان داده می‌شود.

## 🛠 خدمات

| خدمت | توضیح |
|---|---|
| 🤖 ربات تلگرام و بله | ربات فروش، پشتیبانی، عضویت و اشتراک، پنل ادمین داخل ربات، اتصال به درگاه پرداخت |
| ⚙️ اتوماسیون و اسکریپت | جمع‌آوری داده از سایت‌ها، گزارش‌گیری خودکار اکسل، اتصال سرویس‌ها به هم |
| 🚀 لندینگ پیج | طراحی سریع و مدرن با پنل مدیریت محتوا و فرم‌های متصل به ربات یا پیامک |
| 🛒 فروشگاه اینترنتی | سبد خرید، درگاه پرداخت ایرانی، مدیریت سفارش و موجودی |
| 🌐 وردپرس | نصب، شخصی‌سازی قالب حرفه‌ای، المنتور، ووکامرس، افزایش سرعت و امنیت |

**ابزارها:** Python · FastAPI · Django · Next.js · React · Tailwind · WordPress · WooCommerce · PostgreSQL · Docker · Linux

## 🤝 روند همکاری

1. **بررسی نیاز:** گفتگو درباره هدف و امکانات، و ارسال برآورد دقیق زمان و هزینه
2. **فازبندی:** کار به چند مرحله تقسیم می‌شود و پرداخت مرحله‌ای از طریق سیستم امن سایت انجام می‌شود
3. **پیش‌نمایش زنده:** در طول کار، نسخه آنلاین را می‌بینید و نظر می‌دهید
4. **تحویل:** سورس‌کد کامل، راهنمای نصب و آموزش کوتاه
5. **پشتیبانی:** ۳۰ روز رفع اشکال رایگان بعد از تحویل
