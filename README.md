# سلام 👋 من توسعه‌دهنده وب، ربات و اتوماسیون هستم

سایت‌های کدنویسی‌شده، فروشگاه اینترنتی، ربات‌های تلگرام و بله و اتوماسیون کارهای تکراری می‌سازم؛ **سریع، تمیز و با پشتیبانی بعد از تحویل.**

---

## 🌟 نمونه‌کارها

### 🏢 وب‌سایت شرکتی هیروسان — [www.herosunco.ir](https://www.herosunco.ir)
وب‌سایت رسمی گروه تولیدی و بازرگانی هیروسان، توزیع‌کننده قطعات یدکی خودرو در کرمان و جنوب شرق ایران.

- طراحی و کدنویسی اختصاصی با PHP (Yii2)، JavaScript، CSS و MySQL، بدون قالب آماده
- صفحات: خانه، درباره ما، برندها، محصولات، رویدادها، فرصت‌های شغلی و وبلاگ
- ریسپانسیو برای موبایل و تبلت، با تمرکز بر سرعت و اعتمادسازی برای مشتری
- معرفی زنجیره تأمین، برندهای همکار و سبد محصولات

🔗 **[مشاهده سایت](https://www.herosunco.ir)**

#### 🛠 داشبورد مدیریت محتوای اختصاصی (CMS)
پنل فارسی که تیم هیروسان با آن همهٔ محتوای سایت را بدون نیاز به برنامه‌نویس به‌روز می‌کند.

- مدیریت وبلاگ، رویدادها (گالری عکس و فیلم)، برندها با کاتالوگ PDF، محصولات، لوگوهای صفحهٔ اول و متن صفحات
- پشتیبان‌گیری خودکار از ۲۰ نسخهٔ آخر و بازگردانی با یک کلیک
- کوچک‌شدن خودکار عکس‌ها موقع آپلود و ابزار پاک‌کردن فایل‌های بی‌استفاده
- تنظیمات سئو برای هر مقاله، بخش دریافت رزومه و ورود امن فقط برای مدیران

🖥 **[امتحان نسخهٔ نمایشی داشبورد](https://abolfazl-mirolyae.github.io/herosun-demo/cms/)** — تغییرات فقط در مرورگر شما می‌ماند.

### 🤖 رادار پروژه‌های فریلنسری (ربات تلگرام + بله) — در حال راه‌اندازی
رباتی که سایت‌های فریلنسری ایرانی را ۲۴ ساعته بررسی می‌کند، پروژه‌های مرتبط را پیدا می‌کند و با کمک هوش مصنوعی قیمت، زمان تحویل و متن پیشنهاد آماده می‌کند.

- پایتون، asyncio، API تلگرام و بله، SQLite
- هوش مصنوعی (DeepSeek / سازگار با OpenAI) برای نوشتن پیشنهاد و دستیار مذاکره با کارفرما
- دکمه‌های تایید، ویرایش و رد؛ ثبت درآمد ماهانه و گزارش پیشرفت تا هدف
- ۱۱ آزمون خودکار؛ اسکریپت آماده برای اجرای ۲۴ ساعته روی سرور لینوکس (systemd)

> کد این پروژه خصوصی است؛ در صورت نیاز، دموی زنده نشان داده می‌شود.

### 📋 کارتابل — مدیریت کار و اتوماسیون اداری سازمان
وب‌اپلیکیشن فارسی و راست‌به‌چپ برای مدیریت وظایف، پروژه‌ها و کارهای اداری تیم، با تقویم شمسی و ربات بله؛ طراحی و ساخته‌شده برای استفاده روزانه در یک شرکت واقعی.

- وظایف، پروژه‌ها، کانبان و تقویم شمسی؛ وظیفه سریع و جستجو و فرمان با Ctrl+K
- اتوماسیون اداری: درخواست‌ها با تایید چندمرحله‌ای، نامه‌های اداری، مرخصی، جلسات و صورتجلسه
- گفتگوی لحظه‌ای و جلسه آنلاین (WebSocket)، یادداشت‌های «روی صفحه» و ظاهر شیشه مایع (Liquid Glass)
- ربات بله: اعلان کارها، تایید درخواست، ثبت مرخصی و ورود با کد یک‌بارمصرف
- پایتون، FastAPI، SQLAlchemy، SQLite؛ آزموده با ۲۰۰ کاربر هم‌زمان، ۳۶۱ آزمون خودکار و بررسی امنیتی

🔗 **[دموی زنده](https://abolfazl-mirolyae.github.io/kartabl-demo/)** · [مخزن دمو](https://github.com/abolfazl-mirolyae/kartabl-demo)

> کد اصلی این پروژه خصوصی است؛ دمو شامل تصاویر واقعی و یک بخش تعاملی است.

### 🎮 فارسی‌ساز بازی Blasphemous 2 (متن‌باز)
ترجمه‌ی کامل و محاوره‌ای بازی Blasphemous 2 به فارسی، با نصب‌کننده‌ی یک‌کلیکی که هر کسی می‌تواند استفاده کند.

- بیش از ۲۳۰۰ متن: دیالوگ‌ها، آموزش‌ها، آیتم‌ها، دعاها، منوها و DLCها
- موتور متن فارسی با پایتون: چسباندن حروف، چیدمان راست‌به‌چپ و شکستن خط برای TextMeshPro، با کلیدهای آموزش درست سر جایشان
- رفع افت سرعت با ساخت فونت از پیش (SDF) و رفع باگ شمارنده‌ها با بررسی لاگ‌های خود بازی
- اندازه‌گیری کادرهای متن از فایل‌های UI بازی؛ نصب، حذف و پشتیبان‌گیری خودکار؛ تست خودکار و آزموده داخل بازی
- Python · UnityPy · Unity · TextMeshPro · FreeType · PyInstaller

🔗 **[مخزن و دانلود نصب‌کننده](https://github.com/abolfazl-mirolyae/blasphemous2-farsi)**
